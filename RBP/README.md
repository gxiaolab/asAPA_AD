# RNA-Binding Protein (RBP) Analysis

This directory contains analyses used to investigate potential **RNA-binding protein (RBP) mechanisms** associated with putative functional asAPA variants.

The workflow consists of three complementary approaches: enrichment within experimentally determined RBP binding sites, prediction of allele-specific effects on RBP binding, and sequence motif enrichment surrounding prioritized variants.

## Workflow

Scripts are numbered according to their execution order and are divided into three analysis modules:

```text id="qkl3sx"
Putative functional asAPA SNPs
              │
              ├── 1–3. ENCODE eCLIP enrichment
              │       └── Enrichment within experimental
              │           RBP binding sites
              │
              ├── 4–6. DeepRiPe analysis
              │       └── Predicted allele-specific
              │           effects on RBP binding
              │
              └── 7–12. Motif analysis
                      └── Sequence motifs enriched
                          around functional SNPs
```

Required helper scripts for individual analysis steps are included in this directory.

## Analysis modules

### Scripts 1–3 — ENCODE eCLIP enrichment

These scripts evaluate whether putative functional asAPA SNPs are enriched within experimentally identified RBP binding regions from **ENCODE eCLIP** datasets relative to control variants.

### Scripts 4–6 — DeepRiPe analysis

These scripts use **DeepRiPe**, a deep learning framework for predicting RBP binding from RNA sequence, to evaluate the predicted consequences of alternative alleles on RBP binding.

### Scripts 7–12 — Motif enrichment analysis

These scripts evaluate sequence motifs surrounding putative functional asAPA SNPs to identify motifs enriched within the prioritized variant set. Motif discovery and enrichment analyses were performed using **HOMER2**.

## External tools and resources

This workflow uses the following external tools and datasets:

* **ENCODE eCLIP** — experimentally determined RBP binding datasets used for enrichment analyses. (https://www.encodeproject.org/)
* **DeepRiPe** — deep learning framework used to predict RBP binding and estimate allele-specific changes in predicted binding. (https://github.com/ohlerlab/DeepRiPe)
* **HOMER2** — sequence motif analysis software used to identify motifs enriched around prioritized asAPA variants. (http://homer.ucsd.edu/homer//motif/motifFinding.html)

Software versions, model specifications, analysis parameters, and formal citations are provided in the accompanying manuscript.

## Running the analyses

Scripts within each analysis module should be executed according to their numerical prefixes.

The three modules address complementary aspects of RBP regulation and may have distinct input requirements. File paths and computational parameters should be updated for the user's local computing environment.

## Notes

* ENCODE eCLIP data provide experimentally determined RBP binding information but originate from the HepG2 and K562 cell types represented in the ENCODE datasets rather than human brain tissue.
* DeepRiPe results represent computational predictions of changes in RBP binding and should not be interpreted as direct experimental measurements of allele-specific binding.
* Motif enrichment identifies sequence patterns associated with the prioritized SNP set.
* Control SNP sets and putative functional SNP sets used in these analyses were generated by the corresponding upstream analyses described in the manuscript.
